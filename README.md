# Python Mini Projects - Expense Tracker

## About the Project

This repository contains four beginner-friendly Python mini-projects developed to practice Python programming concepts and improve problem-solving skills.

These projects demonstrate the practical implementation of Python fundamentals, including functions, loops, conditional statements, object-oriented programming, and file handling using JSON and text files.

## Projects Included

### 1. Student Management System
A menu-driven application to manage student records.

**Features:**
- Add new student records.
- View all student details.
- Search students using roll number.
- Update student marks.
- Delete student records.
- Store student information using JSON files.

**Technologies:** Python, JSON, File Handling.

### 2. Quiz Application
A simple command-line quiz application that allows users to answer multiple-choice questions.

**Features:**
- Load questions from a text file.
- Display multiple-choice questions.
- Check answers automatically.
- Calculate the final score.
- Save quiz scores in a text file.

**Technologies:** Python, File Handling, Conditional Statements.

### 3. Library Management System
A menu-driven application for managing library books.

**Features:**
- Add new books.
- Issue available books.
- Return issued books.
- View all book details.
- Track book availability status.
- Store book records using JSON files.

**Technologies:** Python, OOP, JSON, File Handling.

### 4. Expense Tracker
A simple application to record and manage daily expenses.

**Features:**
- Add expenses with date, category, and amount.
- View all recorded expenses.
- Calculate total expenses.
- Store expense records using JSON files.

**Technologies:** Python, JSON, Functions, File Handling.

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/Python-Mini-Projects.git
   ```

2. Open the project folder.

3. Run the required Python project:

   ```bash
   python student_management.py
   ```

   Run the other project files similarly.

**Note:** The Quiz Application requires a `question.txt` file containing questions in the following format:

```text
Question|Option A|Option B|Option C|Correct Answer
```
